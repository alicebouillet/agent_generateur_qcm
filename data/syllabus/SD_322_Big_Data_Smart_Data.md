# Syllabus : Big Data & Traitement de Données Distribuées
- **Code UE** : SD_322
- **Filière** : Intelligence Artificielle & Data Science
- **Semestre** : S9
- **Crédits ECTS** : 5 ECTS
- **Volume horaire** : 80h (25h CM, 55h TP)
- **Responsable** : Dr. Marc Parenthoen (marc.parenthoen@univ-poitiers.fr)

## 1. Description du Cours
Ce cours de 3ème année couvre l'ingénierie des données massives : architecture de grappes (clusters Hadoop YARN), traitement distribué par mémoire avec Apache Spark (Spark SQL, DataFrames, GraphX), ingestion de flux en temps réel avec Apache Kafka, et bases de données non relationnelles (NoSQL Cassandra, MongoDB).

## 2. Prérequis Obligatoires
- UE préalable recommandée : SD_106 - Bases de Données Avancées
- Programmation orientée objet en Python (POO)
- Notions de parallélisme et systèmes d'exploitation Linux

## 3. Compétences Visées & Acquis d'Apprentissage
- Développer des pipelines de transformation Spark en PySpark optimisés pour le passage à l'échelle.
- Configurer et consommer des topics de messages sous Apache Kafka.
- Concevoir un schéma de données NoSQL adapté aux patterns d'écriture et de lecture massifs.
- Diagnostiquer les goulots d'étranglement (skew, shuffle) sur un cluster de calcul distribué.

## 4. Modalités d'Évaluation
- Projet d'architecture distribuée Spark/Kafka en cluster : 60%
- Contrôle continu sur machine (requêtage PySpark) : 40%

## 5. Bibliographie & Ressources
- *Learning Spark: Lightning-Fast Data Analytics*, Jules S. Damji et al. (O'Reilly).
- *Kafka: The Definitive Guide*, Gwen Shapira et al. (O'Reilly).
