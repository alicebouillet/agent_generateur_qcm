# Syllabus : Bases de Données Avancées & Requêtage pour la Data
- **Code UE** : SD_106
- **Filière** : Intelligence Artificielle & Data Science
- **Semestre** : S6
- **Crédits ECTS** : 5 ECTS
- **Volume horaire** : 70h (20h CM, 50h TP)
- **Responsable** : Dr. Marc Parenthoen (marc.parenthoen@univ-poitiers.fr)

## 1. Description du Cours
Ce cours de fin de 1ère année ingénieur SD approfondit la gestion des bases de données relationnelles et non relationnelles : optimisation de requêtes SQL complexes, indexation B-Tree, procédures stockées, et passerelles de requêtage direct via Python (SQLAlchemy, psycopg) et R (DBI, RPostgreSQL).

## 2. Prérequis Obligatoires
- UE préalable recommandée : TC_101 - Mathématiques, Statistique & Informatique
- Bases de données relationnelles (modèle E/A, clés primaires/étrangères, jointures simples)
- Syntaxe de base Python et R

## 3. Compétences Visées & Acquis d'Apprentissage
- Optimiser des plans d'exécution de requêtes SQL sur de gros volumes de données.
- Concevoir une base de données analytique en étoile ou en flocon.
- Connecter et requêter programmatiquement des bases de données depuis des notebooks Jupyter.
- Manipuler des structures semi-structurées JSON/XML au sein de bases relationnelles.

## 4. Modalités d'Évaluation
- TP noté sur serveur PostgreSQL : 50%
- Mini-projet de conception et d'interrogation de base de données métier : 50%

## 5. Bibliographie & Ressources
- *PostgreSQL High Performance*, Gregory Smith (Packt Publishing).
- *Database System Concepts*, Silberschatz, Korth, Sudarshan (McGraw-Hill).
